# HR Workforce Analytics & Attrition Dashboard

## Project Overview

This Excel-based HR analytics project analyzes employee attrition, workforce characteristics, major risk factors, and the estimated financial impact of employee turnover.

## Dashboard Features

* Total Employees, Attrition Rate, Average Tenure, and Estimated Attrition Cost KPIs
* Attrition analysis by Department
* Attrition analysis by Age Band
* Attrition analysis by Salary Band
* Attrition analysis by Overtime
* Attrition analysis by Satisfaction Level
* Interactive Gender and City slicers
* What-If Analysis for replacement-cost scenarios

## Key Insights

* Overall employee attrition rate: **29.33%**
* Employees working overtime have a significantly higher attrition rate.
* Employees with low satisfaction show the highest attrition risk.
* Marketing and Operations have comparatively high attrition rates.
* Estimated attrition cost under the six-month replacement assumption: approximately **₹17.07 crore**

## Tools and Techniques Used

* Microsoft Excel
* Power Query
* Excel Tables
* Advanced Formulas
* PivotTables
* PivotCharts
* Slicers
* What-If Analysis
* Conditional Formatting

## Dataset

The project contains **1,200 employee records** covering employee demographics, income, tenure, department, satisfaction, overtime, and attrition.
